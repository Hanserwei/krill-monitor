# Krill Monitor v0.2.3

Android 与 Web 更新为 Teal Material 3 Expressive 界面，支持系统浅深模式；模型排行展开后可以查询输入、输出及缓存明细，缓存占比与官网统计口径一致。

- Android 重设计概览、用量、线路、API 密钥和设置页面；修复系统主题、字号切换时页面状态丢失。
- Web 增加桌面侧栏与宽屏分栏、手机底部导航，以及浏览器前进、后退和地址直达；本地运行与 CI 升级至 Node.js 26.13.0 LTS。
- 套餐补充获得时间和到期时间，额度窗口按接口实际字段展示，月总额度不再显示空周期。
- 模型明细按需加载，支持缓存、刷新和失败重试；模型、日期范围和账号之间的数据保持隔离，慢网刷新时保留展开状态。
- 账号接口部分失败时保留上次成功数据；Web 通过固定白名单的匿名同源中转探测线路，延迟包含中转开销。

Android 最低支持 Android 7.0（API 24）；本地 Key 库需要 Android 11（API 30）及以上和安全锁屏。Web 密钥页面引导使用 Android 或官网，不保存完整密钥副本。本项目为独立第三方客户端，非 Krill 官方产品。

下载 `krill-monitor-0.2.3.apk`；`SHA256SUMS` 和 `ANDROID-SIGNING-CERT.txt` 分别提供文件校验值及签名证书指纹。已安装正式版可使用同一正式签名覆盖升级；调试版签名不同，不能直接覆盖，卸载会删除其本地 Key 库。
