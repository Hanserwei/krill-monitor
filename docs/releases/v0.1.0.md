# Krill Monitor v0.1.0

首个正式版本，提供 Android 与 Web 账户监控；本项目是独立第三方客户端，并非 Krill 官方产品。

- 支持邮箱验证码、密码和 TOTP 登录，查看钱包、赠金、多份套餐，以及最近 7 / 30 天的费用、请求、失败数、Token 和模型排行。
- 匿名探测三条线路，并展示公开渠道的模型状态、最近 24 小时历史及可用性能数据。线路延迟不代表模型首 Token 时间。
- Android 支持 API Key 创建、重命名、轮换、撤销、永久删除和渠道配置。本地保存的 Key 加密存储，每次查看或复制需要系统认证。

Android 应用最低支持 Android 7.0（API 24）；本地 Key 库需要 Android 11（API 30）及以上和安全锁屏。官网已有 Key 如果没有本机副本，无法找回完整值。Web 暂不支持 Key 管理；OAuth、企业工作区、白名单、消费限额和余额回退配置编辑暂未实现。

下载 `krill-monitor-0.1.0.apk` 安装；`SHA256SUMS` 提供文件校验值，`ANDROID-SIGNING-CERT.txt` 提供公开签名证书的 SHA256 指纹。

**正式签名与调试版不同，无法直接覆盖安装。** 卸载调试版会删除其本地 Key 库，请先妥善保留需要的 Key；不要自动卸载。后续版本使用相同正式签名并提高 versionCode 后可覆盖升级。
